Как установить

How to install

  1. Скачайте APK и откройте файл на телефоне. Download the APK and open the file on your phone.
  2. Разрешите установку из этого источника, если система спросит. Allow installation from this source if the system asks.
  3. Откройте приложение и выберите файл кнопкой «Открыть PDF». Open the app and pick a file with the “Open PDF” button.

Что умеет

What it does

  • Открывает PDF откуда угодно. Файл из файлового менеджера, почты или мессенджера открывается в PDF+ — приложение можно назначить обработчиком по умолчанию. Opens PDFs from anywhere. A file from a file manager, mail or a messenger opens in PDF+ — you can set it as the default handler.
  • Видно, где вы в документе. Страницы идут подряд, счётчик показывает «3 / 24», а к нужному номеру можно перейти сразу. You always know where you are. Pages flow one after another, the counter shows “3 / 24”, and you can jump straight to a page number.
  • Мелкий текст читается. Увеличение двойным касанием и пинчем, полноэкранный режим со свайпом между страницами. Small print stays readable. Zoom with a double tap or pinch, a full-screen mode with swiping between pages.
  • Ничего не просит. Файл выбирается системным диалогом: у приложения нет ни одного разрешения и нет доступа в интернет. Asks for nothing. Files come from the system picker: the app has no permissions at all and no internet access.

Пока это только просмотр. Инструменты над страницами — поворот, удаление, объединение — в следующих версиях.

For now this is viewing only. Page tools — rotate, delete, merge — are coming in later versions.

Приватность
